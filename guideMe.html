A quick start to this workspace

Make the next step clear.

ClaudeProjects combines reusable Copilot workflows with script projects. Start with the skill that fits your task, and let its requirements guide the work from idea to release. See the repository instructions for the shared rules.

Pick a workflow

Each skill has one job; use it when that job is needed.

01

/new-script

Plan a new script in a requirements file. It does not create application code.

02

/change-script

Record and analyze a change request for an existing script project.

03

/review-req

Review requirements, scaffold, risks, and acceptance criteria only.

04

/build-script

Implement from reviewed requirements after you explicitly request the build.

05

/review-script

Review implemented source and tests without changing or rebuilding code.

06

/build-exe

Package an approved, current implementation as a Windows executable.

07

/commit-push

Review pending changes, commit, and push when you explicitly ask.

How a project moves forward

Follow the arrows; review outcomes can send work back for another pass.

Start

/new-script or /change-script

Plan a project or request a change.

Specify

Write or update requirements

Agree on behavior, risks, and acceptance checks.

Gate 1 · Requirements

/review-req

Pass requirements review and resolve blockers before implementation.

Explicit request

/build-script

Implement the approved requirements and run checks.

Gate 2 · Code

/review-script

Verify implementation against requirements and tests.

Optional release

/build-exe

Package after code review passes and authorization.
